# Aetheris

*A world small enough to hold, and big enough to get lost in.*

---

## The story before the story

Somewhere between a snow globe and a save file, there's a kind of world we stopped making. Not the sprawling, seven-hundred-hour kind — the *small* kind. A windmill turning on a hill you can hold in your palm. A fox that knows the fire's exact spot. A lake you'd recognize by its lily pads alone.

Aetheris started as a question we couldn't put down: what if a website could feel like *that* — not a page you scroll past, but a place you circle back to, the way you'd revisit a diorama on a shelf, just to see it catch the light differently?

So instead of building a homepage, we built an island. Instead of a hero section, we built a campfire.

## What you're actually looking at

Aetheris is a floating world you explore rather than read. Drag to orbit it like you're turning a globe in your hands. Scroll to lean in close enough to see the fox's ears twitch. Click the glowing points and the island tells you what's there, one small discovery at a time.

**Home Isle** is the anchor — a windmill, a campfire, a forest thick enough to lose a path in, and a fox that's decided this is *its* island too. **Still Mere** sits nearby, quieter — a lake isle where lily pads drift and dragonflies stitch the air above the water.

More isles are coming. That's the point, really — Aetheris isn't a finished place. It's an atlas with empty pages left on purpose.

## Why it matters (to us, and maybe to you)

The internet got very good at being fast and very bad at being *somewhere*. We wanted five minutes of somewhere. Not gamified, not gimmicky — just a small world that rewards the very human instinct to poke around and see what's over there.

If someone opens Aetheris, forgets to be impressed, and just starts exploring — that's the whole project working.

## Built with

- **Next.js** + **React** — the frame the world hangs on
- **Tailwind CSS** — for everything that isn't the island itself
- **Three.js** — every tree, ripple, and low-poly fox
- Deployed on **Vercel**

## Running it locally

```bash
git clone <repo-url>
cd aetheris
npm install
npm run dev
```

Then open `localhost:3000` and start orbiting.

## What's next

More isles. A wider camera path to fly between them. And, eventually, an atlas that feels less like a demo and more like a place people actually keep coming back to — the way you'd check in on a diorama you built once and never quite finished, because it was never supposed to be finished.
